# 策略验证规范

## 数据

- 公共 fUSD Funding Trades 与 Funding Stats 至少 90 天，按端点分页并限速。
- 历史盘口无法可靠回填；从部署日起每分钟保存盘口快照，并在报告中单独披露覆盖期。
- 评估期间不调用任何鉴权写接口。

## 固定切分

时间顺序严格固定为 60 天训练、15 天验证、15 天测试。禁止随机切分。候选只根据训练集排序，验证集用于淘汰，测试集用于最终样本外门槛。

固定基线：

1. 当前 V3 ACTIVE。
2. FRR-only。
3. LIMIT 贴近成交价。

主要目标是净利息除以本金时间。辅助指标包括利用率、平均等待、撤挂率和长期占用。模拟器会明确标记无法从历史数据恢复的维度。

离线回放以 15 分钟为执行间隔，并把每个间隔内的公共成交压缩为按成交量加权的信号点；真实区间成交量仍用于模拟成交。Funding Stats 严格按回放时点可见，禁止读取未来样本。

## 硬边界

优化器只能改变期限池、成交层、订单类型、利率偏移和重定价参数。最低净 APR、最大放贷额、最大比例、最低订单金额、费用和权限不允许由研究候选改变。

## 进入候选的必要条件

- 验证集和测试集的本金时间净收益均高于当前 V3。
- 按日配对 Bootstrap 的 95% 置信区间下界大于 0。
- 安全不变量全部通过。
- 报告只标记 `eligibleForLiveCandidate`；任何上线、占比提升和撤单都必须人工执行。

当前十项评分权重属于 `StrategyV3.py` 的版本化研究模型 `v3-score-2026-07-22`，不属于策略配置，也不在普通 Dashboard 或 API 中开放；验证报告会记录实际使用的模型版本与权重。
