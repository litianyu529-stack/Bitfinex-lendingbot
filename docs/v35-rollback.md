## 私有状态迁移

先停止控制台和 Worker，以 SQLite backup 接口保存当前两币数据库、配置与审计资料。
使用升级前 Schema 16 数据库备份作为输出基底，由 `RollbackV35.py` 投影最新 USD
操作记录到旧版已有字段，不直接使用 Schema 17 库，也不修改源数据库。

迁移拒绝跨币记录、未知交易写入、受保护暂停及真正未完成的调价。
已确认关闭、没有替代订单的历史调价链只关闭执行资格，保留其原始证据。
机器人订单归属、订单创建时间、贷款、账本和历史行情保留；自适应策略与模型授权
不迁入旧 ACTIVE。恢复旧策略后创建必要的旧版调价链，不提高原报价、不重置等待时间。

输出库保持 PAUSED，撤销恢复授权；经过最新账户只读对账及正常预检后才启动 USD。
USDT 贷款和挂单留在交易所，旧版不会管理、撤销或续挂 USDT。私有备份不进入 Git。

## 必要运行修复

已完成初始化的 Schema 16 库不在每次控制台查询时重跑迁移、持有写锁。
初次初始化、旧 schema 升级及历史版本分界补全仍执行；新于 Schema 16 的库拒绝直接打开。
保持连接及时关闭和数据库故障时禁止交易写入，不提高忙等待超时来掩盖锁冲突。

验收包括迁移隔离、订单归属与累计等待、未知写入阻断、历史取消不重放、数据库读写并行，
以及 V3.5 全部既有回归和 `verify.ps1`。工程通过不代表收益超过 V4 或其他产品。
