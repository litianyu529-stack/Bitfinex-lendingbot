# Bitfinex-lendingbot V3.5 发布说明

V3.5 将最近两轮安全恢复和定价调价升级合并为一个正式版本。应用与 HTTP User-Agent 版本为 `0.3.5`，Dashboard 显示 `V3.5`。内部 `RuntimeV3`、`StrategyV3`、状态库文件名及策略协议标识继续保持兼容。

## 无人值守安全与恢复

- 网络、认证、配置、行情、账户快照和 Worker 异常统一进入无写入的 PAUSED 恢复流程；除人工暂停或停止外，满足连续权威快照条件后自动恢复原运行模式。
- 未知提交、未知撤单、小额订单合并及外部挂单接管统一暴露为持久化写入阻断，未完成权威对账前禁止产生新的交易写入。
- 重启后继续处理既有恢复状态，清理已经被权威快照证明失效的观察记录，避免旧状态永久阻塞 LIVE。
- 外部 fUSD 挂单仍需两次权威快照确认后才会被托管，并且只按具体 Offer ID 操作；外部 Credits 不接管、不提前关闭。

## 精确期限定价与单向调价

- 短、中、长期订单只读取其精确期限的市场数据。快速层使用同期限竞争价；平衡层结合同期限锚点、1 小时中位数、24 小时 Q75 和 5% 起始保护；高收益层结合24小时/7天 Q75、IQR 和 12% 起始保护。
- 新订单将创建时的同期限市场落点持久化。快速层和平衡层在第 5 阶段到达固定落点，高收益层在第 7 阶段到达固定落点；市场后续变化只影响新订单。
- 每条订单链采用 10 个期限专属阶段，利率只能持平或下降。短期在 180 分钟、中期在 360 分钟、长期在 1440 分钟到达真实底线。
- 停止执行 `MARKET_RISE` 和 `QUICK_PERIOD_CORRECTION` 旁路。最终底线阶段优先于普通同层冷却和每小时调价限制，但仍遵守交易所写入速率、确认、余额对账和未知写入保护。
- 类型纠正、撤单重挂和策略同步继承原金额、期限、层级、起始时间、阶段及固定落点，重挂利率不得高于当前订单。
- 部分成交后的剩余金额不足 150 USD 时不撤单，Dashboard 明确显示“低于交易所重挂最低金额”。

## 数据与升级

状态数据库升级为 Schema 16，新增订单意图及调价链的固定市场落点。迁移前仍执行在线备份，迁移过程保持事务性；现有策略、历史审计、分支、标签和用户配置不被删除。旧订单链若意外存在，会在首次权威同步时固定一次同期限落点，且不会高于原始起价。

首次运行 V3.5 时，状态库会在 `schema_meta` 中写入不可变的本机上线时间。状态接口围绕该时间提供更新前后等长窗口的订单与成交统计，包括精确期限、金额、加权日利率和加权等待时间；后续重启不会移动分界，因而可以持续评估 V3.5 相对旧版本的变化。

本次发布不改变资金池比例、层级比例、APR 底线或已经配置的各期限最终调价时间，也不增加成交救援机制。
