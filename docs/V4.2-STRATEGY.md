# V4.2：可执行的资金循环与调价

新增引擎 `adaptive_net_yield_v3`、算法 `ADAPTIVE_NET_YIELD_V3`。V3 旧策略、V4.0、V4.1 保留；升级代码不会自动替换 ACTIVE、覆盖资金风险上限或启动真实放贷。

## 调价与收益计算

V4.2 把下一次资金循环的净收益效率用于普通调价排序：`365 × 预期首循环净利息 ÷（本金 × 预期首循环占用天数）`。占用包含撤挂空档、剩余成交等待及贷款实际持有期。已经等待但尚未成交的订单使用条件剩余等待，不能把每次评估都当作刚开始排队，也不能仅随订单年龄增加便推定已经排到最前。

普通保留报价未成交时，不再计入未经执行的“明天换价并滚动放贷”收入。返还后的再放贷现金流只属于模拟中与实际执行一致的后续动作。64 条固定种子的配对行情路径继续检查 120 天保守增量净利息，不能为了短期更易成交而忽略长期收益损失。

后续续贷沿用相同的自身成交等待统计，每次重新撮合；2 天续贷不使用更长期限的借款量。情景起点采用已观察的价格和需求，FRR 历史按日期对齐，缺日只能沿用此前观察并保留缺口，不能拼接未来记录。比较金额采用 0.00000001 精度，避免等价现金流被浮点尾差错误拒绝。被动替代单只按可执行的最小金额估值，尾款留在现金且不凭空计息。

每次评估比较保留、升价、降价、换期限及等待。普通调整继续要求最短保留时间、冷却、连续两次优势确认、每币最多 12 次／小时及账户写入预算。报价违法、突破资金上限及等待租约到期采用安全处理；撤单未确认前不提交替代单，遇到不明确写入先对账，不能盲目重复。

重估间隔在完整收益计算之前检查，间隔内仅返回当前资金与等待原因，不复用旧计划提交订单。余额不足最小合法单、且没有机器人旧单需要比价时，仍校验模型和 FRR，但跳过候选估值。同一期限、类型和提交价格的重复候选在估值前去重。

估值超过时间或事件预算时，仅阻止本轮新挂单及普通调价，并清除尚未成立的连续优势确认；不把计算预算耗尽记为永久模型故障。机器人旧单的收益底线、资金上限违规或被动租约到期仍独立检查，必要时确认撤单回到现金，不因估值未完成继续无限等待。真正的模型、行情、账户或持久化故障继续保护暂停。

`reprice_gain_apr` 的控制台/API 单位为百分点，默认 `0.25`；内部使用年化小数 `0.0025`。这是下一资金周期的效率提升门槛，不是承诺账户年化提升。120 天保守增量净利息不得为负，长期新分配仍须通过相对短期滚动方案的收益优势检查。

## 有时限的被动挂单

没有已确认即时需求时，允许把合法报价作为有时限候选比较，避免一律将没有当前借单视为无法挂单。默认 `passive_wait_minutes=60`，允许 15～360 分钟；每币最多一张最小合法金额的被动单，不吸收尾款，不设固定高价资金比例。

到期重新估值。相同报价只有出现新的独立需求证据才能续等，同一资金链的被动等待累计不超过 360 分钟；重复盘口快照不能作为新证据反复续期。没有合格替代方案或续期证据时，确认撤单后资金回到现金状态，不能无期限滚动延长等待，也不能为避免闲置机械突破收益底线。租约与证据按币种持久化，重启继续沿用原截止时间。

短中期净报价底线 5%、31～120 天净报价底线 10%、最长 120 天、长期资金上限 95% 及现有浮动上限继续生效。金额不足最小单时保留余额；可放贷资金因底线、需求、风险或租约限制未挂出时展示原因。

## 类型、运行恢复与证据

四类订单继续参与比较：LIMIT 固定；FRR 为 Variable 零偏移；Delta Fixed 成交前随 FRR 更新、成交后固定；Delta Variable 成交后继续浮动。Fixed 允许负偏移，Variable 不允许负偏移。规划、客户端校验及模拟交易所使用相同合法性契约；明确参数拒绝不能无限重试同一报价。公共逐笔或盘口无法确认订单撮合族时，需求兼容性标记未知，不能假定 LIMIT 需求足以证明 FRR 会成交。

V4.2 默认不接管外部挂单，该设置在 API、配置镜像及策略 JSON 中保留。显式授权接管时，启动凭证绑定预检展示的具体订单 ID；账户或订单变化后需要重新预检。恢复和后续运行不沿用授权接管未来出现的外部订单，外部资金占用仍计入风险上限。旧单币控制入口和旧监督恢复不能授权 V4.2，需通过 V4 的币种预检及启动流程。

临时行情或 FRR 失效时停止写入；新鲜数据、模型校验、账户对账和未决写入恢复后，按该次实际运行目标恢复。旧的已结束恢复记录不能覆盖新的 LIVE 目标。人工暂停、模型损坏、日志持久化失败及权限故障保留相应保护。数据读取的实际观察时间不能沿用一次较长账户同步开始前的时间，也不能将旧历史样本重标为新鲜数据。

`operationalReady` 仅表示运行验收，`eligibleForLiveCandidate` 表示严格收益研究，两者分别展示。V4.2 仍使用冻结模型；准备任务显式绑定币种和引擎，新模型需重新预览、保存、应用与预检，不能运行中自动替换。

控制台展示下一周期效率、120 天保护、预计成交概率、剩余等待、累计等待、等待到期时间及置信度；未知数显示未知。断联时保留金额作为历史快照，不依据缓存将运行状态认定为已停止。停止时间与原因来自生命周期记录，没有证据就标记原因未知。

全账户今日、30 日和累计利息包含升级前贷款；新增成交、本金与精确可归属的新贷款净利息另列。账本无法精确关联新贷款时显示未核算，不能把旧贷款收入包装成 V4.2 盈利验证。
