## 评分口径

评分衡量的是单笔订单的**策略执行质量与可审计性**，不是借款人信用评级，也不是收益保证。

- 30 分：交易所确认、金额/期限/层级可追溯。
- 25 分：利率底线与“只降不升”保护；`market_rise` 事件在此项扣分。
- 25 分：相对该期限硬底线的收益空间（短期/中期/长期硬底线分别为 0.02088% / 0.02409% / 0.02891% 每日）。
- 20 分：成交、规范阶段重挂、活跃挂单或审计闭环；已成交但缺 funding trade、无撤单审计事件会在此扣分。

A：90–100（执行良好）；B：80–89（可接受但需补审计）；C：70–79（需复盘）；D：<70（应暂停同类路径）。
