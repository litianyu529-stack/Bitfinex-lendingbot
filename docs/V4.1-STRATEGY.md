# V4.1 策略：LIMIT 与 FRR 系列比较

V3 旧策略与 V4.0 策略保留。新增引擎 `adaptive_net_yield_v2`、算法 `ADAPTIVE_NET_YIELD_V2`。
升级不替换 ACTIVE，不启用真实放贷；V4.1 模板仅用于独立草稿与研究。

## 类型与计息

| 界面类型 | 提交类型与参数 | 成交后的计息 |
|---|---|---|
| LIMIT | LIMIT，明确日利率 | 固定 |
| FRR | FRRDELTAVAR，偏移量0 | 随 FRR 浮动 |
| FRR Delta Fixed | FRRDELTAFIX，正或负偏移量 | 匹配前随 FRR 更新，匹配后固定 |
| FRR Delta Variable | FRRDELTAVAR，正偏移量 | 随 FRR 加偏移量浮动 |

Hidden 尚未进入此版本。各类型可独立勾选，必须至少选择一种。
浮动订单沿用可配置的 Variable 最高占比，包含已有贷款、已有挂单及拟议挂单；默认模板沿用现有10%上限。

## 收益比较与局限

沿用共同120天窗口、64条固定种子路径、保守第10百分位排序、长期优势检查、共享需求预算及撤挂冷却。
四种类型同价格的候选共享盘口容量，不重复占用需求。

FRR系列必须有至少20天真实FRR历史及未超过行情有效期的当前FRR。历史成交利率不能替代FRR。
预测使用历史两天FRR块，相对于当前FRR重定基准；Delta Fixed 在模拟成交时固定，Variable 在持有期间逐日计息。
自身成交等待表与持有样本按币种及类型隔离；样本稀疏时只使用保守市场先验，不借用其他类型的自身成交参数。
历史FRR不能精确还原待成交订单未来的排队位置；候选成交概率依然是当前报价的估计，不是成交保证。

当前报价仍须达到净年化底线，FRR系列还须通过持有期净年化第10百分位检查。
FRR系列挂单在成交前随FRR变化，可能在两次检查之间以低于报价门槛的利率成交；
**浮动贷款的未来利率也可能低于底线，此检查不构成收益保证，也不能强制提前收回贷款。**
预览显示各候选类型、预测收益、置信度及浮动利率风险说明。

## 资格与隔离

V4.1 模型、候选指针、评估报告和回放检查点与 V4.0 分开；模型版本参与策略与预检凭证绑定。
研究任务请求显式包含 currency 和 engine，恢复沿用原任务引擎。
研究不调用鉴权客户端或交易所写接口。

除原有60/15/15切分、收益与Bootstrap验收外，V4.1要求训练集各类型至少20条自身资金链，
验证和测试窗口的FRR有效覆盖均至少95%。不足时保持“研究数据不足”，不能启用实盘。
回放同时比较各类型的独立方案与综合分配方案，公共成交只作为模拟容量。

正式启用仍需暂停对应币种、绑定合格冻结模型、预览、保存、应用、预检及人工启动。

## 输入修复

空白或无效的最大放贷比例返回中文输入提示，不能隐式变成100%或暴露 decimal.ConversionSyntax。
