# V4.0 策略（自适应净收益）

界面名称为“V4.0 策略”，软件版本 `ADAPTIVE_NET_YIELD_V1`，策略引擎 `adaptive_net_yield_v1`。
V3 时代的引擎在界面中称为“V3 旧策略”；旧记录缺少标识时仍使用 `legacy_v3`。升级不会替换 ACTIVE，也不会启用真实放贷。

## 使用流程

1. 在 USD / USDT 各自的策略区域点击“载入 V4.0 策略草稿模板”。默认2～30天净年化底线5%，31～120天10%，长期风险上限95%。
2. 对每币启动研究评估或影子观察。研究只读取本地 Worker 记录，无鉴权客户端、无交易所写接口。
3. 数据不足时模型保持研究状态。公共逐笔历史须有分页覆盖凭证，历史盘口不能从K线补造；影子订单不能充当自己的成交样本。
4. 研究合格后选择冻结模型 ID，暂停该币种，重新预览、保存和应用，再进行预检并人工启动。

未通过研究、模型损坏、币种不匹配或决策日志不能持久化时，禁止新动作。
软件测试通过与收益研究通过分别验收。本次开发验收仅使用模拟账户。

## 报价与分配

只创建可见 LIMIT，期限不超过120天。底线为扣费后的成交报价年化；含等待和闲置的账户年化另算。普通费用按至少15%保守计算，界面的优惠勾选本身不能证明账户享有优惠。

候选来自近期兼容成交、借款报价、竞争供给及当前机器人挂单。借款期限不超过出借期限且借款价不低于报价才计入需求。候选共享剩余需求预算，每分配最低合法金额重新估计排队成本，同期限同价合并，每币至多8单。

64条固定种子的历史日块路径比较共同120天窗口，包含首笔等待、持有、提前归还和归还后短期复投的闲置。按净收益第10百分位排序。长期还要高于短期滚动方案至少0.5个百分点；95%是长期占用上限而非分配目标。已有贷款计入占用，不强制收回或兑换币种。

等待采用0/5/15/30/60/120/360/720/1440分钟离散生存表，部分成交按剩余本金观察、取消与未结束订单保留删失样本，按资金链计有效样本。期限组和条件表向同币种父级收缩，先验20条资金链。贷款持有估计包含尚未归还贷款。缺少条件盘口的记录只能用于父级估计；低样本模型明确低置信度。

盘口用于竞争供给估计，不能识别精确队列。归还后短期复投使用历史短期成交日块，并计入每两天至少一小时复投空档。模型每日只生成研究候选；正式使用的模型保持冻结。模型在训练截止150天后到期（预留30天验证与测试，随后最多120天有效），到期阻止新动作。

## 执行保护

Worker最多每10秒检查，至少每60秒评估；账户或盘口变化可提前触发。普通撤挂须保留5分钟、冷却至少2分钟、连续两次确认，保守资金时间净年化优势至少0.25个百分点且配对收益增量P10为正。每币每小时最多12次普通调整，并受账户写入预算约束。安全底线、金额上限和订单合法性违规不等待普通冷却。

写入前 fsync 决策日志并复用持久化订单意图。撤单确认后还要等权威账户快照中源订单消失，才允许使用释放资金。未知响应进入既有恢复流程，不盲目重试。明确拒绝保留原单并恢复链状态。暂停单币不影响另一币；停止两币仍在公共区域。

## 研究与接口

沿用 `/api/strategy/v4/{preview,draft,apply,discard}`，显式 currency。模型校验和参与计划、预览和启动凭证绑定。

研究接口全部要求 USD / USDT：

- `GET /api/research/v4/status?currency=USD`
- `POST /api/research/v4/evaluate`
- `POST /api/research/v4/shadow/start`、`shadow/stop`
- `POST /api/research/v4/cancel`、`resume`

任务异步执行，取消后可恢复原评估时间窗口；回放按版本、策略和模型绑定保存已完成比较的检查点。重启后未完成任务显示 INTERRUPTED，需主动恢复。

公共历史重叠时间分页、ID去重。满页时间戳无法继续推进时记录缺口，不能用最早/最晚时间证明完整。

统一事件回放比较原ACTIVE、同底线旧策略、FRR和近成交价LIMIT与新引擎。现金流在成交、归还及窗口结束时逐秒累计，未归还贷款计入已发生利息。公共成交容量只作为模拟上限。训练60天、验证15天、测试15天，测试集不拟合。测试每日差用3天移动块、2000次Bootstrap；95%下界、验证/测试及悲观排队/提前归还场景必须共同支持优势。

FRR研究依赖历史资金统计中的真实FRR；缺少该数据的结果不能替代真实浮动利率表现。旧V3聚合回放保留兼容入口，其未知等待与撤单统计显示未知，不用于新策略资格证明。

## 私有文件与交付

无数据库结构变更。模型、检查点、研究结果和决策日志位于数据库目录下 `research/USD` 和 `research/USDT`；正常配置即 `.state/research/`。这些文件、账户历史与密钥均被Git忽略。

运行 `verify.ps1`，其中新纯策略核心独立要求分支覆盖率至少90%。模拟账户页面覆盖双币隔离、桌面与手机布局；开发验收不启动真实放贷。
