# V4 无人值守自动自愈

V4 的 Dashboard 与 Worker 是两个独立进程。Dashboard 为每次启动生成新的守护会话，Worker 使用独立进程锁和跨版本 LIVE 锁。只有本次 Dashboard 会话中完成人工确认的 LIVE 才拥有临时自动恢复授权；Dashboard 重启会使旧授权失效并保持 PAUSED。

网络超时或断开、`IncompleteRead`、Bitfinex 408/425/429/5xx、行情过期、账户数据缺失或不守恒以及 SQLite 临时 busy/locked 会进入只读恢复。恢复期间禁止 submit、cancel、重定价和钱包转账，只读取权威账户、行情和认证历史。退避固定为 30 秒、60 秒、2 分钟、5 分钟，之后每 5 分钟无限安全重试。

自动恢复要求两次连续且至少间隔 30 秒的干净快照：可用余额已知，Offers/Credits/Loans 完整且去重，账户金额守恒，至少两个市场信号新鲜，并且没有未决写入。第二次确认只恢复目标模式；同一周期仍禁止写入，下一个正常策略周期才重新计算并执行。

未知写入会同时检查活动 Offers、认证 Funding Offers 历史和 Funding Trades 历史。唯一匹配或两次权威证据确认不存在后，还要再取得两次新的干净快照。多个候选或证据矛盾会永久保持人工 SAFE，不会猜测或重复提交。

Worker 每轮开始和结束写入心跳。五分钟没有心跳时，Dashboard 先向记录的具体 PID 写入安全退出请求；十秒后仍未退出才终止该进程，然后用同一会话授权启动新 Worker，先恢复未决意图并做全新只读预检。

人工暂停或停止、HTTP 401/403、配置或权限错误、构建/配置变化、数据库损坏或迁移失败、未知程序异常和多候选写入都要求人工处理。V4 不提供自动恢复参数或总开关，也不包含 Windows 开机自启和 Dashboard 自身的系统级拉起。
